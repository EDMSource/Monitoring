# System Monitor Web App

веб-приложение для мониторинга состояния системы в реальном времени с поддержкой интерактивного управления процессами.

## Как запустить
Для работы приложения не требуется установка интерпретатора Python или компиляция кода:

1. Перейдите в раздел [Releases](https://github.com/EDMSource/Monitoring/releases/tag/v1.0.0).

2. Скачайте файл SystemMonitor.exe.
3. Запустите файл на исполнение.
4. Откройте в браузере адрес: http://localhost:5000

## Основные возможности
- Real-time мониторинг загрузки CPU, RAM и диска.
- Интерактивная таблица процессов с сортировкой и фильтрацией системных задач.
- Система защиты критически важных процессов (Smart Protection), исключающая случайное завершение служб Windows (System, Explorer, Svchost и др.).
- Современный пользовательский интерфейс с поддержкой темной темы (Dark Mode).

## Технологический стек
- Языки: C++, Python, JavaScript, CSS.
- Фреймворки: Flask.
- Инструменты: Visual Studio, PyInstaller.
- Особенности: Автономный бинарный файл, собранный методом статической компиляции.

## Сборка проекта (для разработчиков)
Для самостоятельной сборки приложения выполните следующие шаги:

1. Установка зависимостей:
   pip install flask

2. Компиляция системного агента C++:
   g++ monitor_agent.cpp -o monitor_agent.exe -static

3. Упаковка в единый исполняемый файл:
   python -m PyInstaller --onefile --console --name "SystemMonitor" --add-data "monitor_agent.exe;." --add-data "interface.html;." SubClass.py
